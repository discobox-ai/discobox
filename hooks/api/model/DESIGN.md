# API Model Design

`model` exposes stable hooks socket API models. It combines generated aliases for
simple reusable OpenAPI schemas with handwritten-style DTOs for request/response
objects and API views that should not leak generator-specific optional wrappers
into service, client, or CLI code.

## Responsibilities

- Provide a small import path for stable contract-facing types such as `Hook`,
  `HookStatus`, `Event`, run/change/snapshot/queue views, request payloads,
  response wrappers, and enum-like schema values.
- Keep simple alias definitions generated by `go generate` so the package tracks
  OpenAPI component files automatically.
- Keep compatibility DTOs in this package instead of the parent `api` package.

## Generation

Do not edit `aliases_gen.go` by hand. Update the component YAML files under
`../openapi/components/model` and run:

```bash
cd ..
go generate ./...
```
