# policy review notes

- Every slot that takes a type refuses the reserved words that do not fit it: `anything` is only a resource type, `anywhere` only a deny's scope type. A reserved word needs no definition, so one accepted in the wrong slot is an unread widening — `allow … in anything *` once validated as an allow with no scope.
- `Evaluate` is the only place parts are combined. A caller that cannot decide a part passes `Unknown`, never `No`, and never fakes a part to force a verdict: `Unknown` on a deny's part also keeps that deny from refusing.
- Every word `Format` writes unescaped — an action, a type — is one `Validate` holds to printable ASCII with no quote, comma or `$`. Allow a safe set there; never list the unsafe. Unicode's "printable" let a non-breaking space, a curly quote, then a blank braille pattern and a Hangul filler through, and `repository⠀$primary.repo⠀of⠀organization "*"` read as the primary repository while it stored any scope of a made-up type.
- Quoted text — a name, a condition — is written with `strconv.QuoteToASCII`, never `strconv.Quote` or a set of "safe" Unicode. A list of lookalikes missed U+02EE, and letters-digits-marks still showed U+1425, U+030E after a space, and blank hieroglyphs: `when "its base is mainˮ unless ˮit is a draft"` read as a when narrowed by an unless while it stored one condition with no unless.
- A word `Validate` refuses still counts as used. One refusal must not bring a second error, "defined but no statement uses it", that tells an agent to delete a definition it needs.
- In `Within`, a name is a pattern if `path.Match` reads any of it as syntax — `*`, `?`, `[`, and the escape `\` — and a variable's value is escaped before it is compared. `release-\main` once passed as a literal that `release-[^m]*` matches, while it names the excluded `release-main`; a value of `*` would have read as every name.
